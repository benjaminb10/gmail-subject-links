# Privacy Policy

Gmail Subject Links does not collect, store, transmit or share any data.

- The extension runs only on `mail.google.com`, inside your browser.
- It reads the subject lines displayed on the page to find URLs and turn them into links. This happens locally and nothing is saved.
- It makes no network requests, uses no analytics and no cookies, and has no server.
- It requests no browser permissions besides running on `mail.google.com`.

The source code is public: https://github.com/benjaminb10/gmail-subject-links

Questions: open an issue on the GitHub repository.
